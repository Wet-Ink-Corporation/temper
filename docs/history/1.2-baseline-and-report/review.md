## Checked and found sound
- CRLF sources: line numbers, diff parsing and the scanner are all correct (a CRLF file with a new `unwrap` fails with the right line).
- lib and lib-test duplicates, and clippy vs rustdoc `missing_docs`, are deduplicated; the baseline counts it once. Build-script lints are collected and attributed correctly.
- A real compile error always fails: E0308 becomes an error, and a non-zero exit with no parsed error falls back to `cargoFailure`. `CARGO_BUILD_WARNINGS=deny` in CI is overridden. `tighten` and `init` refuse on errors.
- A staged file or crate-dir rename passes. A swap in the same crate fails. A count rise on an untouched line fails. A base that isn't an ancestor uses the merge base.
- CI base selection is correct:
  - pull_request uses `origin/$GITHUB_BASE_REF`;
  - push uses `before`, falling back to totals when `before` is all zeros or unreachable (`cat-file -e`);
  - schedule and dispatch use `origin/main`.
- The report and upload steps run on ratchet failure (`always()`), and the comment step fails safely on forks (`continue-on-error`). The upload-artifact SHA is the real v7.0.1. actionlint and shellcheck are clean.
- HTML escaping holds against `<script>`, `onerror` and `</td>` in messages, notes, base and paths. Markdown escapes `#`, `[]`, `!`, `@`, `<`, `&` and pipes in table cells, and drops partial code spans.
- A report of 10,000 findings is 6.3 KB and 57 lines of Markdown and 54 KB of HTML, well under the 65,536-character comment limit.
- Vendoring: the example copy is byte-identical to `scripts/`, `VERSION` is 1.2.0, and CRLF is tolerated.
