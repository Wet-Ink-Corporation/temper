# Decision log

This page lists every question raised through [Weigh-In](https://github.com/Wet-Ink-Corporation/weigh-in) while temper 1.1 and 1.2 were built, while this repository was set up, and while temper 2.0 (the Rust port, [`docs/plans/temper-2-rust-port.md`](../plans/temper-2-rust-port.md)) was planned. That covers questions an agent raised, assumptions it made, deferrals and its own calls. Each one was decided by the owner, defaulted as a reversible call, or dismissed. Anchors were rewritten to be relative to this repository. Line numbers are as they were when the item was raised, except where an anchor was repointed after its target moved. A CHANGELOG anchor names its release heading, which does not move.
