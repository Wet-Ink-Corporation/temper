# Crate charter: `temper-domain`

## Purpose
temper's pure policy: the masking lexer and scanner rules, the manifest policy, config and glob matching, the verdict and fingerprint rules, the findings, baseline, ratchet and report models with their renderers, and every message text the hooks print (port plan §1.3). Phase 1a brought the scanner's lexer, test regions, counts and first six rules, Phase 1b 40 more rules with their look-around and keep predicates, Phase 1c the finders and the last regex rules (58 of 60), Phase 1d the doc rules (60 of 60), path classification and the new-hit difference, Phase 2a the manifest policy, the config and glob matching, and Phase 2b the hook protocol types (events, outcomes, the skill marker rule and telemetry rows), `Timestamp` and the JS value model read from JSON, and Phase 3a the review verdict rules and `Fingerprint`; the rest arrives phase by phase.

## Layer
domain.

## Allowed dependencies
- Workspace crates: none.
- Third-party, each added by the phase that first uses it (D10, wi-b03273): `regex`, `toml` (features `std`, `parse`, `preserve_order`), `sha2`, `serde`, `serde_json`, `thiserror`. `serde` is in since Phase 1d.2 with `std` only: `Hit`'s `Serialize` is hand-written (1d-12), and `derive` comes with the first derived DTO. `toml` and `serde_json` are in since Phase 2a; `sha2` since Phase 3a, without default features (no `alloc` or `oid`); `toml` is read through `toml::de::DeTable`, since `toml::Table` needs the `serde` feature D10 does not list. Dev only: `proptest`, `insta`.

## Invariants
- No `std::fs`, `std::process`, `std::env`, `SystemTime::now` or threads: every input arrives as a value (ARC-02).
- Output that 1.x writes (hook messages, JSON fields, report text) is byte-identical to 1.x unless §2.4 of the port plan lists the divergence (D16).

## Errors
Typed `thiserror` enums per module, added with the code that needs them (ERR-01, H-09).

## Test strategy
- Unit tests beside the code; property tests (proptest, in use since Phase 1a) for the lexer, the scanner, the glob matcher and JSON string escaping; `insta` snapshots for rendered reports. Commit `proptest-regressions/` when proptest writes one.
- Scanner-level tests port `tests/scan.test.mjs` in its order, one module per 1.x test group (`src/scan/tests/`, support in `src/scan/tests.rs`); manifest tests port `tests/toml.test.mjs` and the domain half of `hooks.test.mjs`'s manifest cases (`src/manifest/tests/`), with each expected text printed by 1.x on the same input; lexer, region and count tests use values computed by running 1.x on the same input.
- Parity with 1.x is checked by the port's harness (§2.2), not here.
- Run: `cargo test -p temper-domain`.

## Do not
- Do not read files, spawn processes or read the clock or the environment; take the value as an argument.
- Do not add a dependency outside the list above without a decision (H-16).
